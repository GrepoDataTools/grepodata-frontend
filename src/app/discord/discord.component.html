List of commands

10 slash commands

Configuration

/help

Shows a list of all commands

/world[world]

Sets the default world for your Discord to [world]

e.g. /world en141 changes the default world to en141

Daily scoreboard

/today

Shows today's scoreboard for the default world

/today[world]

Shows today's scoreboard for the given world

e.g. /today nl74 shows the scoreboard for nl74

/yesterday

Shows yesterday's scoreboard for the default world

/yesterday[world]

Shows yesterday's scoreboard for the given world

e.g. /yesterday nl74 shows yesterday's scoreboard for nl74

/alliance

Shows today's alliance scoreboard for the default world

/alliance[world]

Shows today's alliance scoreboard for the given world

e.g. /alliance nl74 shows today's alliance scoreboard for nl74

/alliance[world] [day]

Shows the alliance scoreboard for the given world · [day] can be today or yesterday

e.g. /alliance nl74 yesterday shows yesterday's alliance scoreboard for nl74

Player search

/search[name]

Search for players by name
